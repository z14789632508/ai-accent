# ai-accent

> 不看词，看分布。

**AI 口音的体检表。** 它不告诉你"别用首先其次综上所述"，它量的是那些词表管不到的东西：一条消息多长、一轮发几条、段与段之间长短差多少、句子收不收口。

因为禁词表删得掉词，删不掉形状。

---

## 为什么不是又一份词表

2026 年 GitHub 上解决"AI 味"的项目，绝大多数是词表：把所有"总的来说 / 首先 / 其次 / 综上所述 / 希望对你有帮助"列成黑名单，命中就重写或罚分。

问题在于这组映射是**反向的**：

| | |
|---|---|
| **指标** | 输出里不出现这些词 |
| **目标** | 说的话像人 |

指标一旦被当成目标，它就不再是目标的代理，而是目标的替代品。词被删了，模型不是学会像人说话，而是学会**换个地方八股**——这是 Goodhart's Law 的标准形态，压下去的那块鼓到别处，就是水床效应。

本仓库把这件事从"观点"变成"可测量的现象"。方法是：**不去看它说了什么词，去看它输出的形状分布，和真人语料比。**

### 一个真实样本（同一个人设、同一个后端模型）

模型侧 490 条真实 QQ 回复（1481 段），人类侧 526,350 条群聊消息（77 群 / 43 个说话人）作为基线：

```
metric                          value      p10      p50      p90     dev  verdict
------------------------------------------------------------------------------------
chunk_len_p50                      16        7        9       16     0.0  ok
chunk_len_cv                    0.362    0.767    1.483    2.569   -1.57  LOW
end_punct_rate                  0.035    0.056    0.082    0.169   -1.81  LOW
turn_chunks_median                3.0        1      2.0        5     0.0  ok
turn_share_3                     0.89    0.038    0.073    0.105   25.53  HIGH (明显)
turn_chunks_entropy             0.665    1.152     2.56    4.434   -1.35  LOW
within_turn_cv_median           0.198    0.434     0.54    0.665   -3.23  LOW (明显)
sentence_len_entropy            1.471    1.265    1.507    1.776     0.0  ok
```

三行就够说明问题：

- **89% 的回复恰好 3 段**，真人 7%。方向偏离 25.5 个带宽——不是"稍微有点像"，是几乎没变过。
- **段内长度 CV 0.20**，真人 0.54。每一次都是"二十字 / 二十字 / 二十字"，整齐得不像说话。
- **连发条数熵 0.67**，真人 2.56。真人有时一条就停，有时连发八条；模型几乎每次都是三条。

而**词级标记命中率是 0.0%**。禁词表在这份语料上是完美通过的——八股一个词都没出现，形状一点没变。

这就是本仓库的全部立论：**词表测的东西，和八股真正待的地方，不是同一个地方。**

## 装

```bash
pip install -e .
aiaccent baseline            # 看已装的基线
```

零依赖，纯标准库，Python ≥ 3.9。

## 用

```bash
# 体检一份语料（jsonl：每行是一个 turn 的段列表；或 txt：空行分 turn、行分段）
aiaccent audit my_replies.jsonl --register chat

# 顺带出处方：采样参数 + 可直接粘进 system prompt 的"形状卡"
aiaccent audit my_replies.jsonl --register chat --prescribe

# 只出处方
aiaccent prescribe my_replies.jsonl --register chat

# 两个语料对比（改前 / 改后）
aiaccent diff before.jsonl after.jsonl

# 从真人语料里挖最像人的若干轮，当 few-shot
aiaccent mine human.jsonl --register chat -k 20
```

`--register` **没有默认值**。日常聊天和学术写作的形状标准不一样，混用会把两边都带坏：`prescribe` 在 `formal` 下只给采样参数，不给形状卡。

## 指标在测什么

| 指标 | 测的东西 | 像模型的方向 |
|---|---|---|
| `chunk_len_p50` | 一条消息多长 | 偏长 |
| `chunk_len_cv` | 所有消息长度的离散度 | 偏小（都差不多长） |
| `end_punct_rate` | 有多少条以句号/问号收尾 | 偏高（每条都收口） |
| `turn_chunks_median` | 一轮发几条 | — |
| `turn_share_3` | 恰好 3 条的比例 | 偏高 |
| `turn_chunks_entropy` | 条数的不可预测程度 | 偏低 |
| `within_turn_cv_median` | 一轮内部几条之间长短差多少 | 偏低 |
| `sentence_len_entropy` | 句长分布的熵 | *实验性* |

最后一项标 experimental 是有原因的：它对分箱宽度和语料口径极其敏感。同一批真人在私聊里是 2.50，在群聊里只有 1.5–1.7——因为群聊里全是"草""笑死""1"这种一两个字的消息，把最短的 bin 堆满了。**跨语料直接比这个数会得出相反结论**，报告里必须印分箱和语料来源。

`dev` 是偏离量，单位是"一个带宽"（带外才计，带内为 0）。它不是分数，只是幅度——0.5 和 25 的差别，就是"有点偏"和"几乎没变过"的差别。

## 参数不都是有效的

处方里会推荐采样参数，但**不同后端支持的不一样**，照着改可能一半是空转。

以 DeepSeek `/chat/completions`（2026-11 核实）为例：

| 参数 | 是否生效 |
|---|---|
| `temperature` | 生效（0–2，默认 1） |
| `max_tokens` | 生效 |
| `stop` | 生效 |
| `top_p` | **`deepseek-flash` 非思考模式固定 1.0，传了被忽略** |
| `frequency_penalty` | **已标 deprecated，"will not take effect if you pass it to the API"** |
| `presence_penalty` | **同上** |

也就是说，在这类后端上 L1 实际只有 `temperature` 和 `max_tokens` 两个真旋钮，靠调参把八股调掉基本不成立——**形状得靠提示（L2）和语料（L3）去压**。工具的处方会按后端过滤：

```bash
aiaccent audit my_replies.jsonl --register chat --prescribe --provider deepseek
```

它会把不生效的参数标成"此后端不生效"，而不是继续推荐你去调一个空转的旋钮。


## 三个坑（我自己踩过）

1. **采样单位是 turn，不是 message。** 模型侧一次回复里用 `\n\n` 分的段是 chunk，整条回复才是 turn。早期我把多次回复按 120 秒合并成一个 turn，`turn_chunks_median` 直接虚高到 9，所有结论都偏了。
2. **人类基线不能用自己造的样本。** 拿"我觉得像人"的几句话当基线，等于用观点校准观点。必须用真实语料，且要说明语料口径（私聊 / 群聊 / 论坛）。
3. **基线文件只存统计量，不存原文。** `baselines/*.json` 里只有 p10/p50/p90。语料原文本地留着，不进仓库。

## 它**不**做什么

- **不出总分。** 一个 0–100 的"人味分"一旦存在，就会立刻变成新的优化目标，然后被刷。这里只出逐项数据和方向。
- **不内置词表。** 词表是另一层的事，且已经被验证治不了本。
- **不判断内容好坏。** 它只说"这段输出的形状和真人的分布不一样"，不说写得好不好。

## 对照实验（已跑完）

不是只有观测。`experiments/01` 事先写死了判读规则，然后在 DeepSeek 上真跑了两组各 300 条：同一个 prompt 池、同一套采样参数，唯一差别是 B 组的系统提示多加了一段 17 个词的禁用表。

| | A（无禁令） | B（词表禁令） |
|---|---|---|
| 禁用词命中 / 千字 | 0.36 | **0.20（↓44%）** |
| 句末标点率 | 90.4% | **99.1%（z=4.90, p<1e-5）** |
| 单段回复占比 | 90.0% | **97.0%** |
| 连发条数熵 | 0.676 | **0.235（95% CI [−0.66,−0.22]）** |
| 段内长度 CV | 0.436 | 0.394 |

词少了，形状更死了：**四个结构指标全往"更整齐"的方向走，而且都显著**。这就是水床——压下去的那块从词汇层鼓到了结构层。
