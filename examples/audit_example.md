## 怎么读这张表

`dev` 是偏离量，单位是"一个带宽"（带外才计，带内为 0）。它不是分数，只是幅度。

- **模型的所有幅度大的偏离都在"更整齐"那一侧**：三段率 25.5×带宽、段内 CV 3.2×带宽。方向全都指向"输出形状几乎不变"。
- **真人的大偏离在"更随意"那一侧**：整体长度 CV 2.05×带宽、句长熵 3.77×带宽。人是有时一句话十个字、有时一条两个字。
- 真人也有一个 2.5×带宽的 `turn_share_3`——15% 的轮次恰好连发三条。但 15% 和 89% 不是同一件事：前者是习惯，后者是常数。

这就是本仓库想说的：**词表看这两个语料都是完美通过的**（模型侧词级八股标记 0.0%），但形状一眼就能分开。

## 处方（`--prescribe`）

```
== sampling ==
  temperature        1.0–1.2
  presence_penalty   0.3–0.5
  frequency_penalty  0.2–0.4
  max_tokens         60.0–80.0

== shape card (贴进 system prompt) ==
回复形状：长度 3 到 26 字之间随便给，长短交错，允许一条只有两三个字；
经常只发一条就停，想补一句再发一条，不要攒成一大段；
句子可以断在半路，不用每段都收得整整齐齐；
不是每轮都要问回去，也不是每轮都要收尾总结。

== notes ==
  - [明显 25.5×带宽] 恰好 3 段占 89%（人类 7%）：不是禁止三段，是让段数跟着内容走。
  - [明显 3.2×带宽] 段内长度太整齐（CV 0.20，人类 0.54）：长短交错，允许参差。
  - [轻微 1.6×带宽] 整体长度分布太窄（CV 0.36，人类 1.48）：有的轮次该长，有的该只有两个字。
  - [轻微 1.4×带宽] 连发条数太可预测（熵 0.67，人类 2.56）：偶尔只发一条就停。
```

处方里没有一条"不要用 XX 词"。全是形状。
