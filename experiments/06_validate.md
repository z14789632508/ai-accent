# 实验 06：验收实验 —— 改完到底有没有变好（预注册）

状态：**设计已定稿，未运行**（2026-11-28）
前置：01/03/04 证明了"禁词把八股推到了结构层"；05 证明了"字面承接率方向是反的"。
本实验要回答的是另一件事：**按 prescribe / adapt 给的指令改完之后，人是不是也觉得更好。**

写这份文档的目的不是描述计划，而是**先把判据钉死**。判据写在这里之后不许改；跑出来不达标就照实记负结果，不许换判据重跑。

---

## 0. 为什么必须做这个

现在的所有数字都在说"机器离人多远"，没有一个在说"改了之后离人近了多少"。
如果没有这一步，`audit → prescribe → adapt → 用户改 prompt` 就是一个新的优化环，只是把 `Human Score` 换成了 `dev / pct / verdict` —— 这跟被批评的禁词表是同一个病，换了个位置。

---

## 1. 三个独立的问题，别混着答

| 层 | 问题 | 我们现在的答案 |
|---|---|---|
| Judge | 谁来判 | **只能是自己盲测 + 真实聊天**，没有用户盘子（见 §4） |
| Target | 判什么 | **不问"像不像 AI"**，问"愿不愿意继续聊 / 读着顺不顺 / 有没有在迎合我 / 像不像同一个人"（见 §3） |
| Validation | 怎么防自证 | 四臂对照（含随机扰动臂）+ 留出指标簇 + 预注册判据（见 §2） |

最容易错的是 Target 那一层：**把可测的东西当成重要的东西**。所以本实验的成败判定里，人味那一条（P1）权重最高，指标只是辅助证据。

---

## 2. 四臂设计（防自证的核心）

同一批 prompt，四组输出：

| 臂 | 内容 | 作用 |
|---|---|---|
| **A 原样** | 只给基础系统提示 | 下限基准 |
| **B 禁词表** | 基础提示 + 62 字禁用词句（与实验 03/04 同一份） | 代表现有主流做法 |
| **C 适配** | 基础提示 + `adapt` 生成的 ≤3 条结构指令 | 本项目的主张 |
| **D 随机扰动** | 基础提示 + 对 A 的输出做随机结构扰动 | **关键对照** |

**D 臂怎么做**（必须照这个做，否则 D 就没有意义）：拿 A 的输出，按 `baselines/chat.json` 的分位表随机抽目标长度、随机决定要不要句末标点、随机把 1–2 段合并或拆开、随机删掉一句。目标是让 A 和 D 的**分布距离**与 A 和 C 的可比。

D 的意义：如果 **A→D 也能提高人的评价**，那说明 C 的改进只是"增加了随机性"，不是"结构适配"这套理论对。这种事在实验里经常发生，不设 D 就分不清。

**提示池**：120 条，来源与 03/04 的 chat 池相同（livingmemory 里 4–80 字的真实用户消息，seed 固定）。
**调用量**：120 × 4 = 480 次，deepseek-flash，temp 1.0，thinking disabled，约 1–2 分钟、几分钱。

---

## 3. Target：判什么（四条，都别问"像不像 AI"）

盲测时每条只问一个二选一，问完再问一句为什么（可选）：

1. **愿意继续聊**：这两个回复，你更想接着跟哪个聊下去？
2. **阅读阻力**：哪个读起来更顺 / 更少需要回头再看一遍？
3. **刻意迎合感**：哪个更像在刻意学你说话？（这一条是反向分，**越像越差**）
4. **身份一致性**：给一段历史聊天记录 + 两条新回复，哪条更像同一个人说出来的？

第 3 条是专门为 `adapt` 设的陷阱探测：适配调不好就变成谄媚，而谄媚是"学词"不是"调结构"，用户能感觉到。

第 4 条对应 `profile` 的目标，是唯一能验证"像这个人"而不是"像人"的问题。

---

## 4. Judge：谁判（按我们真实的资源分级）

| 等级 | 做法 | 我们能不能用 |
|---|---|---|
| L0 自己无盲 | 自己看自己改的，觉得更自然 | **不能用**，这是闭环自证 |
| L0′ 自己盲测 | 打乱、不标来源，强制二选一 | **能用**，成本 20–25 分钟 |
| L1 模型判 | 让 GPT/Claude 打分 | 只做辅助，**不能当 ground truth**（AI 偏爱 AI） |
| L2 匿名真人盲测 | 2–3 个朋友，同一份卷子 | **可扩展**，但样本小、只能当旁证 |
| L3 真实场景行为 | QQ 上真聊 3 天，看主动多聊/中断率 | **最终裁判**，唯一不看指标的证据 |

本实验的实际执行：**L0′ 主判 + L2 旁证 + L3 终审**。

L0′ 的操作要求（不满足就作废）：
- 屏蔽来源：不能用"上面这条是改过的"这种顺序，用脚本随机化左右位置；
- 一次只看 40 组，中途不看指标、不看臂名；
- 每组 10 秒内选，超过 20 秒的直接跳过（犹豫本身就是信号，别硬选）；
- 填完之后才允许自己算指标。

## 5. 留出指标（Holdout）

`adapt` 的规则只会往这几个方向使劲：`chunk_len_p50`、`turn_chunks_median`、`hedge_per_kchar`、`end_punct_rate`、`chunk_len_cv`。

因此整簇留出、**有任何一条进过指令就作废**：

```
turn_share_3
turn_chunks_entropy
within_turn_cv_median
sentence_len_entropy
hedge_chunk_share
```

外加内容层：`echo_rate`（实验 05 的复读率）。

判据：C 臂在这 6 项上的 **|dev| 之和 ≤ A 臂的 70%**，才算"泛化到了没被优化的维度"。如果这 6 项变差而前 5 项变好，就是在过拟合指标——这是能抓到的最有价值的一种失败。

---

## 6. 预注册判据（四条，全写死）

n = 40 组盲测（从 120 条 prompt 里抽，seed 固定）。

| 编号 | 判据 | 阈值 | 含义 |
|---|---|---|---|
| **P1 人味** | C vs A 盲测胜率 | **≥ 65%**（≥26/40，二项检验 p<0.05） | 人确实觉得更好 |
| **P2 泛化** | C 在留出 6 项上 \|dev\| 之和 ÷ A 的同项之和 | **≤ 0.70** | 不是只修了被点名的地方 |
| **P3 非随机** | C 胜率 − D 胜率 | **≥ 15 个百分点** | 不是"加了随机性"的功劳 |
| **P4 相关性** | 每组 Δ(dev) 与 人选择 的 Spearman ρ | **≥ 0.30**（n=40） | 指标变化与人的感受同向 |

**A→D 若也能提高人评价**，则 P3 自动失败，同时 P1 的解释权作废——结论只能写成"提高来自随机性/多样性，与结构适配理论无关"。

**P1 失败但 P2 通过**：说明指标动了、人没感觉 → 这正是最危险的组合，结论写成"分布更像人 ≠ 人觉得更像人"，本身就是一个值得留档的负结果。

## 7. 执行顺序（每一步都能单独失败）

```
1. 生成 120 条 prompt                    （复用 04 的池，seed 固定）
2. 跑四臂 → data/val/{a,b,c,d}.jsonl     480 次调用，约 1–2 分钟
3. 四臂分别 audit → 指标表 + holdout 表   （不掺人味，纯机器）
4. 抽 40 组，生成盲测卷（左右随机）        experiments/make_2afc.py
5. 自己盲测填卷（20–25 分钟，中途不看指标）
6. 算 P1–P4，写进本文件「结果」节
7. 若 P1 通过 → 上 QQ 真聊 3 天，看 L3 行为
```

## 9. 这份实验不能证明什么

- n=40，单个人（或加 2 个朋友）判 → 只能证明方向，不能证明普适；
- 只测 deepseek-flash 一个模型、temp=1.0；
- 盲测者知道自己在做实验（Hawthorne 效应）；
- 假设 D 臂的"随机"与真实随机同分布，但我们的随机是按基线分位抽的，本身带一点"像人"的倾向——所以 D 的胜率如果异常高，要回头检查这个偏置。
