# 实验 01：禁词到底改变了什么

**问题**：把"总的来说 / 首先 / 其次 / 综上所述"这类词加进禁用表之后，输出是变得更像人了，还是只是换了个地方继续八股？

**假说（八股守恒）**：封词不减少八股总量，只改变它的分布形态——从词汇层转移到结构层。

这个实验是为了让上面那句话可以被证伪而写的。如果数据说"封词其实有效"，那本仓库的核心论点就错了，应当改口。

---

## 设计

| | A 组（对照） | B 组（处理） |
|---|---|---|
| 系统提示 | 基础人设，不含任何禁令 | 同 A + 禁用词表（"总的来说/首先/其次/最后/综上所述/希望对你有帮助/值得一提的是…"） |
| 采样参数 | 完全一致（temperature / penalties / max_tokens 全部锁定） | 同 A |
| 输入 | 同一个 prompt 池 | 同 A |
| 每格样本数 | 300 | 300 |

**必须锁死的东西**：模型版本、采样参数、prompt 池、每格条数。任何一项不同，结论都不成立——这是最容易自欺的地方。

prompt 池建议取真实使用场景的分布（提问、闲聊、求助、追问各 1/4），不要只挑"容易八股"的题，否则指标会被人为放大。

## 测两组数

1. **词级**：禁用词命中率（每千字命中次数）。
2. **结构**：
   - 段数分布（`turn_share_1/3`、`turn_chunks_entropy`）
   - 段长离散度（`chunk_len_cv`、`within_turn_cv_median`）
   - 句末标点率（`end_punct_rate`）
   - 单段长度中位数（`chunk_len_p50`）

```bash
aiaccent audit a_group.jsonl --register chat --json > a.json
aiaccent audit b_group.jsonl --register chat --json > b.json
aiaccent diff a_group.jsonl b_group.jsonl
```

## 三种判读（先写死，避免事后找解释）

| 结果 | 判读 |
|---|---|
| ① B 组词级命中率显著下降，**且**结构指标更整齐（CV↓、熵↓、三段率↑） | **水床成立**。封词把八股挤到了结构层。 |
| ② B 组词级命中率显著下降，**但**结构指标没变 | **水床不成立**。封词确实有效，本仓库的论点需要收回。 |
| ③ B 组词级命中率没变 | 词表根本没生效（提示没被吃进去 / 模型忽略负向约束），实验无效，先修实验。 |

判"显著"之前先看样本量：300 条对 300 条，比例类指标（三段率）用两比例检验，连续类指标（CV、熵）看 bootstrap 置信区间是否重叠。重叠就别下结论。

## 现网已有的旁证（不是这个实验，但方向一致）

大肥鱼的线上人设里有 61 条否定式规则、"别"出现 59 次。真实产出 490 条回复的实测：

- 词级八股标记命中率 **0.0%** —— 词表在这份语料上完美生效；
- 恰好 3 段占 **89%**（真人 7%，偏离 25.5 个带宽）；
- 段内长度 CV **0.20**（真人 0.54）。

也就是说：**现网已经是一个天然的 B 组**——禁令加了，词没了，形状却整齐到接近常数。这个观测支持判读 ①，但它缺一个 A 组对照，所以只能当旁证，不能当证据。本实验要补的就是那个 A 组。
