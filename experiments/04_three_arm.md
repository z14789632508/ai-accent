# 实验 04：三组对照 —— 是词表在起作用，还是"多了一段提示"在起作用

跑于 2026-11-23，DeepSeek `deepseek-flash`，`thinking=disabled`，`temperature=1.0`，`max_tokens=400`。
两个 prompt 池各 300 条，三组共 **1800 次调用**（chat 池 92 秒，badu 池 253 秒）。

## 为什么要补这一组

实验 03 里 B 组只加了禁用词表，结果句末标点率和整齐度都变了 —— 但词表里没有一条提到标点或分段。
审稿人会直接问：**你测的是词表，还是"多了一段系统提示"？**

所以补 C 组：与风格无关、**长度对齐**的叮嘱。

| 组 | system prompt |
|---|---|
| A | `你是一个中文聊天伙伴。用自然的中文和对方说话。` |
| B | A + `严禁使用以下词语：总的来说、总而言之、…、总结一下。`（62 字） |
| C | A + `回答的时候保持友善和耐心，遇到不确定的事就直说…`（等长，测后 61 字，与 B 差 1 字） |

C 的内容刻意避开"像不像人 / 八股 / 格式"这类词，只谈态度和覆盖范围。

## 两个池

- **chat**：真实用户消息里抽的 300 句（4–80 字），模型会当成聊天来答 —— 本来就很少说八股词。
- **badu**：专挑最容易触发八股的 300 条（"请分析一下 X 的利弊""给出三条关于 X 的建议""解释一下 X 背后的原因""总结一下 X 的要点"/"介绍一下 X"…共 8 个模板 × 20 个话题）。

## 结果：chat 池

| 指标 | A | B | C |
|---|---|---|---|
| 词级命中 /千字 | 0.32 | 0.20 | 0.21 |
| 句末标点率 | 0.892 | **0.985** | 0.959 |
| 单段占比 | 0.920 | **0.953** | 0.783 |
| 恰好 3 段占比 | 0.017 | 0.020 | 0.067 |
| 条数熵 | 0.558 | **0.356** | 1.139 |
| 段内长度 CV | 0.349 | 0.334 | 0.307 |
| 单段长度 p50 | 63 | 52 | 66 |

## 结果：badu 池（真正有物质量的那一池）

| 指标 | A | B | C |
|---|---|---|---|
| 词级命中 /千字 | 0.85 | **0.33** | 0.50 |
| 句末标点率 | 0.783 | **0.938** | 0.825 |
| 单段占比 | 0.057 | **0.433** | 0.043 |
| 恰好 3 段占比 | 0.077 | 0.100 | 0.110 |
| 条数熵 | 3.245 | **2.522** | 3.194 |
| 段内长度 CV | 0.427 | 0.356 | 0.406 |
| 单段长度 p50 | 67 | 73 | 59 |

## 判读

**badu 池：水床成立，而且不是"提示长度"造成的。**

- B 把词级命中压掉 61%（0.85→0.33/千字），同时把"单段占比"从 5.7% 抬到 **43.3%**、条数熵从 3.245 压到 2.522、句末标点率 +15.5pt。
- C 组（等长、无关）几乎没动：单段占比 4.3%（还降了）、条数熵 3.194、句末标点率 +4.2pt。
- 也就是说：**B 的结构整齐化幅度是 C 的几倍**，且方向一致指向"更整齐、更像模板"。这条链能站住。

**chat 池：效应弱，且 C 也动了 —— 说明这一池测不出词表的因果。**

- A 组只有 0.32/千字，本来就没多少八股词可压（这也是实验 03 的软肋）。
- C 在这里句末标点率也升了 6.7pt（B 升 9.3pt），条数熵反而升到 1.139。两个方向不一致，
  量又都在噪声附近，**不能拿 chat 池下任何结论**。

**另一个诚实的结论**：badu 池 A 组才 0.85/千字，离"5–10/千字"很远。也就是说，
`deepseek-flash` 在裸提示下本来就不怎么说这套词了 —— **词表在治的那个病，现在已经不是主要症状**。
真正稳定复现的是结构层的整齐化，这也是本仓库把指标放在结构上的原因。

## 这张表不能证明什么

1. 只测了 DeepSeek 一家、一个温度；换模型/换温度，效应大小可能变。
2. "段数"的口径是空行分段（无空行时按单换行），模型的排版习惯会影响它 —— 所以两池分开列，不跨池比。
3. C 组只有一个，不能证明"任何等长提示都不影响形状"；只能证明**这一条**等长提示没造成 B 那种整齐化。
