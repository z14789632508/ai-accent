状态：**机器侧已完成（2026-11-28），人侧待填卷。**
预注册在实验 06 里（判据没改），07 只补 06 做不到的三件事：

| 06 缺什么 | 07 怎么补 |
|---|---|
| D 臂没进盲测卷 → P3 不可算 | 卷子 40 组 = 20 组 T vs A + 20 组 T vs D |

## 1. 设置

```bash
set AB_ASTRBOT_CONFIG=<AstrBot cmd_config.json>
python experiments/run_07.py --n 120 --workers 12
```

- 池：`data/ab/prompts.jsonl` 前 120 条（与 06 同一批，可横向比）
- 模型：deepseek-flash，temp 1.0，max_tokens 400，thinking disabled
- A / C / T 各 120 次调用（**360 次，58 秒**）；D 由 A 本地扰动（seed 7000+i）
- C 臂 = `user_style` 2 条 + 「短的是信息不是态度」；T 臂 = 再加 `model_tics` 2 条

**T 臂的完整指令**（5 行）：

```
- 这个用户习惯几乎不写句号（实测 end_punct_rate = 0.036）…句末很少用句号…
- 这个用户习惯长短差得很开（实测 chunk_len_cv = 1.955）…长短交错…
- 这个模型的毛病是对冲词密度偏高（模型默认如此）…别每条都补一句缓冲…
- 这个模型的毛病是每句结尾都问回去（模型默认如此）…允许一轮里不带问句…
- 短的是信息，不是态度：要削的是铺垫、解释、客套；关心、情绪、判断这些半句要留着…
```

## 3. 三条可直接读出来的差别（C vs T）

1. **对冲密度真的降下来了**：7.64 →（C）4.34 →（T）**2.89**，人类 1.25。
   06 里这味药没开时是 8.28 → 7.29 纹丝不动；这次直接砍掉一半多。**第二味药是有效的。**
2. **T 开始分条了**：`turn_chunks_median` C 是 1.0，T 是 **2.0**（人类带 1.4–3.0）。
   C 的改善全靠"每段截短"，T 才第一次碰到"一次说几条"这个维度。
3. **标点更靠近人**：C 的 0.026 几乎贴下边界（"几乎不写"被执行成"基本不写"），
   T 的 0.057 略高但离带更近。频率措辞比绝对措辞稳，但仍会过冲——说明"十句里最多一两句"
   这个锚点还不够硬，下一版要写成"多数句子不带标点，偶尔带"。

## 5. 人侧结果（2026-11-28，一次填完）

40 组、32 有效、8 弃权（#6 #20 #23 #25 #27 #28 #38 #39）。

| 判据 | 结果 | 判定 |
|---|---|---|
| P1 T vs A ≥ 65% | **34/36 = 94.4%**，p≈1e-8 | **PASS** |
| P3 T 比 D 高出 ≥15pp | T vs D **27/27 = 100%**，但 94.4 − 100 = **−5.6pp** | **FAIL（判据写错，见下）** |
| P4 逐条 dev 差 vs 人选择 ρ≥0.30 | ρ = **0.20**，n=32 | **FAIL** |

**P3 是我把判据写坏了。** 它想排除"只要改得更乱就能赢"这个解释，写法却是
`（T 对 A 的胜率）−（T 对 D 的胜率）≥ 15pp`。当 T 对 D 是 100% 时这个差值是负的，
判据自动失败——但它要防的情况恰恰没发生：他 27/27 一次都没给"更乱的那臂"投票。
判据应该写成"T 对 D 的胜率 ≥ 65%"，或者补一组 **D vs A** 的直接配对（现在没有，
所以"乱改能不能赢"仍然只被间接回答）。**结论按预注册报 FAIL，不做追认。**

**P4 失败是有信息量的**：聚合层面能过（P2 = 0.11），单条层面完全测不出他的口味
（ρ=0.20）。说明这套指标说的是"这段像不像人写的"，不是"这段我会不会喜欢"——
后者里有一半是他自己的语境、情绪和关系，任何分布指标都看不到。

### 5.1 A 赢的 2 组

34/36 里他只给了 A 两票（并另有弃权）。共同点仍然是**掺了情绪/玩笑的长句**赢过短句。

### 5.2 八条弃权判词——下一味药的地图

他弃权的理由高度一致，且**没有一条是"长度/标点不对"**，全部指向行为层：

| 组 | 他的原话（节选） | 指向 |
|---|---|---|
| #6 | 「真人不会说后半句，只会说自己看不了视频，如果关系好的话会在后半段损你一句」 | 熟人之间该损，不该解释 |
| #20 | 「我问那句问题的起因就是为了好玩，而不是真的要知道问题答案，真人碰见这问题只会损你」 | 识别"玩的语气"，别当真回答 |
| #23 | 「第二的语境是表示理解我的意图，第一是表示共情」 | 共情 vs 理解意图要分清 |
| #27 | 「1是ai味道重，2是每次拒绝发的都是这句话……我想聊政坛，他可以说：『你疯了？我不想被砍头，别拉着我一块死』」 | 拒绝要开玩笑地拒，且要结合上文 |
| #28 | 「第一的问题是过度谄媚……第二属于没能察觉我情绪比较平常的回答」 | 谄媚 vs 撒娇；察觉情绪 |
| #38 | 「直接回一句『你平常也这么回夸人吗』这样更好……他发这句话既有撒娇的意味也有高兴的情绪」 | 被夸要回敬，别平铺直叙 |
| #39 | 「都太过啰嗦……大可直接问到底说的啥，前面说的都属于是废话」 | 不懂就直问，别铺垫 |

**"损你"出现了三次（#6 #20 #27），"撒娇/谄媚/平淡"两次（#28 #38）。**
这是结构指标完全测不到的层：同样 12 个字，"这话听着像在说社交那点事"和
"你疯了？我不想被砍头"在分布上毫无区别，在人情上差一个世界。

**所以第三味药不是指标，是行为规则**（熟人语境：该损就损、被夸要回敬、
拒绝要开玩笑、不懂就直问、先察觉情绪再回答）。它属于 `adapt` 的 `model_tics` 家族，
但需要"关系/情绪"这两个 adapt 现在拿不到的输入——这也正好接上内容层那条未决线。

## 6. 已知限制

- 判官是被模仿者本人（同 06），存在"我知道该选哪个"的先验。
- 单条 dev 噪声大：`chunk_len_cv` 在单条上几乎没意义（一条消息的段内 CV），
  所以 P4 只是探索性，不应当作结论。
- 只测一个模型、一个温度、一个人。
- P3 判据写法有误（见 5），"乱改能不能赢"缺 D vs A 的直接配对。
